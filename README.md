# Physics-Incorporated 3D Range-Gated Imaging via Geometrically-Refined Optical Priors

## Abstract

Three-dimensional range-gated imaging (3DRGI) offers considerable potential 
for long-range sensing under adverse weather conditions. This work proposes a 
physics-incorporated 3DRGI framework driven by geometric-consistency priors, 
introducing an optics-prior correction mechanism to filter scattering and 
multipath artifacts. A physics-consistent loss function is formulated to align 
network optimization with the range-energy envelope distribution. Experimental 
evaluations achieve a 90% accuracy rate with Mean Absolute Error (MAE) below 
3, across both daytime and nighttime scenarios.
